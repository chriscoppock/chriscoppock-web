This is a sample. Posts are plain Markdown files in `content/posts/`, so you can write them in Obsidian or VS Code.

## How it works

Each file starts with a short block of settings (the title, date, one-line description, and whether it's a draft). Everything after that is the post.

- Set `draft: false` (or delete the line) to publish
- The file name becomes the URL, so `my-first-post.md` lives at `/writing/my-first-post/`
- Run `npm run dev` to preview drafts locally

> Write the long version here first. Then cut it into two or three LinkedIn posts.
